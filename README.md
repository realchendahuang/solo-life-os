## 一、什么是 Solo Life OS？

**Solo Life OS** 是专为超级个体（Solopreneur / 独立开发者 / 数字游民）设计的终身操作系统。

它不是花哨的 Notion 模板，也不是需要月费的商业 SaaS。它是一套纯文本、本地优先、由 Git 纳管并由本地 AI 智能体（Agent）驱动的**数字司令部**。

你只需要一个终端和一个代码编辑器，就能通过自然语言与本地智能体协同，完成从灵感捕获、知识沉淀、多仓库工程调度，到全网高信噪比分发与资产复利的全流程闭环。

## 三、三大不可妥协的设计底线

1. **纯文本，零数据库**：所有数据全为 Markdown 和 JSONL。肉眼可读、Git 可 Diff、毫秒级秒开，数据 100% 掌握在自己电脑中，绝无云端数据锁定；
2. **纯对话直出，零中间文件阻塞**：写稿改稿不调外部脚本，模型内部自检完成，首轮回复直接交付可复制内容；
3. **真实交付导向**：拒绝只进不出的废纸篓，任何灵感最终都会转化为具体的代码提交、实战手册章节或可核验的专业技术推文。

## 四、3 分钟快速上手

### 1. 克隆模版并安装依赖
```bash
git clone https://github.com/realchendahuang/solo-life-os.git my-life-os
cd my-life-os
pip install -r requirements.txt
npm test
```

### 2. 与你的 AI 智能体配合作业
支持直接接入 Google Antigravity、Claude Code、Cursor 或任何支持 Agent Skills 的终端智能体。无需学习复杂的命令行，直接用自然语言对 Agent 发出指令：

- **捕获灵感**：记个点子：本地优先架构在弱网环境下的同步边界。
- **研判选题**：这个选题值不值得写？从架构师克制流帮我给两个切角。
- **起草推文**：用野生黑客流写成推文，单段一句话，零引号，直击痛点。
- **发布与归档**：发完了，帮我入库归档并更新选题状态。

## 五、项目内置技能（Agent Skills）速查

| 技能名称 | 功能定位 | 核心特点 |
|---|---|---|
| `idea-capture` | 随口灵感暂存 | 原话一字不改暂存至 inbox |
| `topic-library` | 选题看板推进 | 待写库、素材库、已发布与已弃用全生命周期流转 |
| `topic-brief` | 选题价值研判 | 纯对话切角分析与事实缺口审计 |
| `post-drafter` | 专业文风起草 | 遵守 13 条绝对禁令红线（零引号、封杀说教辩论腔） |
| `hit-archive` | 资产与指标归档 | 记录发布历史、指标回采与选题回填 |
| `weekly-review` | 周期复盘反哺 | 审视本周产出，持续迭代心智模型 |
